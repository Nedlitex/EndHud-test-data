# Skill-point bars with more than three segments

The skill-point bar (above the controlled operator's HP bar, bottom centre) usually has three
segments, but the game can draw more. Kept out of the sweeps over `Fixtures/*` (the folder is listed
where it is used). Read by `SkillPointBarTests` and the on-screen-display combat gate.
