# Stack digits

Stack badges cut from the owner's controller recordings at 4K (3838x2158): the small dark square
with a white count at the bottom right of the first status icon under the HP bar. Link's stack count is
drawn the same way. Each file is 26x26 px, named `<digit>-<recording>_<seconds>.png` ("fullbattle" is
battle_controller_test_fullbattle.mp4, "fullbattle2" and "fullbattle3" the later ones).

The digits seen in all recordings so far are 2, 4 and 5; no 3 yet. `StackDigits.Shapes` is the
majority shape over 89 badges with 2, 45 with 4 and 56 with 5; eight of each are kept here.
